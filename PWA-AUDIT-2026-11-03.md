## Note: two shared names on purpose

The speech and transcription libraries use fixed names that are not ours: cache `transformers-cache` and IndexedDB `keyval-store`. Other apps that use the same library (Hok Gong, as `app/js/storage.js` says) share them. The code already handles this with care. It deletes only this app's own model files from them and never wipes them whole. I left it alone. This is why two names have no `csreader-` prefix.
